# Codex Task 01 - Build the Earnometry MVP

Work in the GitHub repository `earnometry/earnometry-web`.

Read `PRODUCT_SPEC.md` first and treat it as the source of truth.

Build the first production-ready MVP of Earnometry exactly to that specification.

Priorities:
1. Keep architecture simple and static-first.
2. Use Astro + TypeScript unless the existing repository creates a strong reason not to.
3. Implement the home page and Creator Sponsorship Rate Calculator.
4. Make the calculator transparent, responsive, accessible, and easy to extend.
5. Add tests for the calculation logic where practical.
6. Update README with exact local setup and build commands.
7. Run the build and tests before finishing.

Do not add features outside the specification.
Do not add analytics, authentication, a database, payments, a CMS, ads, affiliate links, or external paid services.

When finished:
- summarize what you changed
- report build/test results
- identify any assumptions
- create a pull request rather than merging directly to main if the Codex environment supports that workflow
